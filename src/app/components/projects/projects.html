Projeto 01 · Destaque

Caminhão API — Rodovias

Gestão de frota de caminhões, com controle de movimentação financeira e operacional.

Frontend

Angular, HTML5, CSS3, JavaScript

Backend

Java + Spring Boot

Banco

H2, rodando localmente

Decisão técnica

Uso de BigDecimal em vez de tipos de ponto flutuante (double/float) para todos os cálculos monetários e de saldo, evitando erros de arredondamento em operações financeiras — crítico num sistema que movimenta valores reais.

GitHub ↗ Roda localmente
Próximos passos

Migração para PostgreSQL e deploy em produção, com potencial de versão white-label para transportadoras.
